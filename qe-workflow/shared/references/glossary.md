# Glossary

- **AC**: acceptance criterion, ID `AC-n`, taken from the story in order.
- **DoR**: Definition of Ready, the conditions that must hold before development and test design start.
- **DoD**: Definition of Done, the exit criteria before a story counts as tested.
- **Quality gate**: rubric-based score of a story; below threshold, the story goes back to the author.
- **Override**: a person explicitly passes a failed gate. It needs a name and a reason and is logged.
- **Self-heal**: an automated fix to a test (never the product) for locator, timing or data drift, delivered as a PR.
- **Run ID**: pipeline run identifier used to name triage and heal outputs.
